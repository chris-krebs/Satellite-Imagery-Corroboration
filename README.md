# Event corroboration with open-source data streams

Can open data (OpenStreetMap outlines, NASA FIRMS heat detections, Copernicus Sentinel-2 imagery)
confirm news-reported fires, explosions and strikes, and how precise must the location be?
A method test on 100 historical events (74 incidents, 26 controls).

Website: https://chris-krebs.github.io/Satellite_Imagery_Corroboration/

## Contents

The repository root is the published website. It is generated by `pipeline/08_WEBSITE/build_site.py`
from the pipeline outputs; the HTML is not edited by hand.

- `index.html`: results, map, method, cases, limits, data and credits
- `events/E001.html` … `E100.html`: the evidence behind each verdict
- `data/`: downloadable data (see `DATA_LICENSE.md`)
- `img/`: Sentinel-2 image panels (contain modified Copernicus Sentinel data 2021–2026)
- `pipeline/`: code, inputs and outputs of every stage (01 events, 02 OpenStreetMap check,
  04 FIRMS, 05 persistent heat, 06 verdicts, 07 Sentinel-2, 08 website).
  `pipeline/README.md` explains each stage and how to run it.

Not included: download caches (re-created on the first run), full-size Sentinel-2 images (the site
keeps web copies) and the FIRMS API key. To rerun stage 04, get a free FIRMS map key and put
`FIRMS_MAP_KEY=...` in a `.env` file in `pipeline/`.
